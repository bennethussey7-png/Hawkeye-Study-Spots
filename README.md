# Hawkeye Study Spots — D2

A fictional University of Iowa study-space guide created for MKTG:4400.

## Publish
1. Upload all files to the root of a public GitHub repository.
2. Settings → Pages → Deploy from a branch → main / (root) → Save.
3. Replace `YOUR-USERNAME` and `YOUR-REPOSITORY` in `robots.txt` and `sitemap.xml` with the real published URL, and commit those changes.
4. Confirm that the four pages, `/robots.txt`, and `/sitemap.xml` load.
5. Verify the website in Google Search Console and submit `sitemap.xml`.

## Important
The conditions and room descriptions are fictional illustrations, not live reports. Every HTML page carries the exact required fictional-site notice at top and bottom.

## Commit requirement
Your professor requires at least four meaningful commits on **different days**. Do not fabricate commit dates.
